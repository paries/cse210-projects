Inheritance is a way for a way to share common attributes and methods with other classes.

The benifit of inheritance is the removing duplication of attributes and methods that share the same functionallity.

A appliction of inheritance could a a tool that makes API calls to a external datasource.
An example would be making calls to a SMS providers API.
One class would be a GetNewNumber class.
Another class would be SendMessage class.
Both of these classes with extend the SMS providers HTTP class that would do all the http auth calls and GETS and POSTS and http error handling.
